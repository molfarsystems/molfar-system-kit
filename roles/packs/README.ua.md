# Набори ролей

Готові набори `.zip` з ролей цього репозиторію. Поставити: скачай файл (**Download raw file**) → Molfar → **Налаштування** → **Архів даних** → **Відновити з архіву** → **Додати**. Потрібен Molfar **2.0.4** або новіший.

Ролі з'являться в каталозі **Експерти**, категорія **Molfar Kit**. Нічого не видаляється; роль з тією самою назвою, але іншим текстом, — спершу питання (**Замінити** / **Зберегти обидва** / **Пропустити**).
