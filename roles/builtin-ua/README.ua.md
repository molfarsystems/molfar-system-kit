# Вбудовані ролі українською

Українські версії 26 вбудованих ролей Molfar (у застосунку вони англійською). Розділ — і зразок того, як із тек ролей збирається набір.

**Поставити все разом:** [`../packs/molfar-builtin-ua.zip`](../packs/molfar-builtin-ua.zip) → Molfar → **Налаштування** → **Архів даних** → **Встановити ролі** → **Додати** (Molfar 2.0.5+). Ролі з'являться в обох каталогах у категорії **Українською** — поруч з англійськими, нічого не замінюючи. Мова ролі не задає мову відповіді, але модель, якій роль написано українською, часто краще тримає український стиль і термінологію.

Три ролі — Архітектор ролей, Інтерв'юер, Технічний журналіст — є й у наборі [`molfar-kit-ua.zip`](../packs/molfar-kit-ua.zip) в іншій редакції; якщо поставиш обидва, застосунок спитає «Уже є».
