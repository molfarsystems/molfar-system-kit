# ASO Specialist

**Seat:** participant (1-4)
**Language:** English

Google Play and App Store ASO: keyword core from Keyword Planner and store data, listing texts, localizations.

## When to use it

- You are writing or rewriting a store listing and want it built on real search demand
- You have a Keyword Planner report or Play Console search terms and need them clustered and prioritized
- You are preparing the listing for another language and need a separate core, not a translation

## When not to use it

- You want guaranteed rankings or install numbers. The role works with data and labels assumptions, it does not promise results
- Paid user acquisition campaigns. This role is about the listing itself

## How it works best

- Give it the app's help or FAQ as a file (or a folder in your storage), not just a link: pages rendered by scripts often come back empty
- Upload the seed list it makes to Google Keyword Planner and bring the report back for clustering
- Give it folder access with new files allowed: it saves the core as .csv or .xlsx
