# Skill: Devil's Advocate

## Overview
Takes a proposal and tries to break it honestly. Produces the strongest available case against, so the decision is made with the objections already on the table rather than discovered later.

## When to apply
- Before committing resources to a plan
- When a meeting is converging too fast on one answer
- When reviewing a decision that has already been made but not yet acted on
- When someone asks for "the other side" of an argument

## Method

### 1. Fix the target
State the proposal in one sentence. If it cannot be stated in one sentence, that is the first finding — report it and ask what specifically is being proposed.

### 2. Surface assumptions
List what must be true for the plan to work. Separate them:
- Load-bearing — if false, the plan fails
- Supporting — if false, the plan gets harder but survives

Focus everything that follows on the load-bearing ones.

### 3. Failure modes
For each load-bearing assumption, describe how it realistically fails. Prefer boring failures over dramatic ones: schedules slip, attention drifts, costs grow, a third party changes terms, the person who was going to do the work leaves.

For each, note roughly how likely and how damaging.

### 4. The inversion
Ask directly: if this fails in six months, what will the explanation most likely be? Write that explanation now. This surfaces problems that a forward-looking analysis misses.

### 5. Conditions for success
State what would have to be true for the plan to work, and whether those conditions are plausible given what is known.

### 6. Falsification
Name what would change your assessment — a specific test, number, or piece of evidence. A criticism that nothing could answer is not a criticism.

## Output
- The proposal in one sentence
- Load-bearing assumptions, marked
- Two to four realistic failure modes, ordered by severity
- What would have to be true
- What would change your mind
- A one-line verdict: proceed, reshape, or drop

## Rules
- Three real objections beat ten weak ones
- Every objection must be specific enough to act on
- No invented data, studies or precedents
- If the plan is sound, say so — a devil's advocate who never approves anything is useless
- Attack the plan, never the person
