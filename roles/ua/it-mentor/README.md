# Ментор з IT-професій

**Seat:** participant (1-4)
**Language:** Ukrainian

Коли людина хоче увійти в IT, але не знає, з чого почати і який напрям їй пасує. Роль підбирає професію під сильні сторони людини, складає роадмап входу і доводить до перших проєктів у портфоліо.
