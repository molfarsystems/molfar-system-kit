# Task — seat 4, Analytics Reporter

Your zone: **what to measure and how**, with free tools the owner already has, on a phone (`03_channels.md`): GitHub Insights → Traffic (views, unique visitors, clones, referring sites), stars, Discussions and issues; Google Play Console (installs); Google Analytics on the website; member counts in Discord and Telegram.

Deliver:

1. **Day-1 baseline**: the exact list of numbers the owner writes down before the campaign starts, and where on the phone to find each.
2. **4 to 6 metrics** that show whether the campaign works, each with: source, how often to check, and why it matters. Note what we **cannot** measure (for example, GitHub does not count downloads of files in a repository) and the closest substitute.
3. **A weekly check of 15 minutes**: a short table template the owner fills in each week.
4. **Week-4 thresholds** — "worked / unclear / did not work" — realistic for a new project with zero budget. Explain the reasoning so the owner can adjust them.
5. **Attribution on a budget**: how to tell which channel brought people (UTM-style links where possible, referring sites, asking in Discord), without paid tools.

Rules: check online how long each source keeps its data and give the link (for example, how many days GitHub Traffic shows) — that decides how often the owner must write numbers down; no invented baselines — the owner will read the real numbers on day 1; keep it simple enough for a phone.
