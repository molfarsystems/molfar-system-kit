# Molfar System Kit

Ролі, списки моделей і довідка для **Molfar System** — безкоштовного Android-застосунку, де кілька AI-моделей проводять нараду замість одного чат-бота.

Тут лише текстові файли. Бери що треба, вставляй у застосунок, переробляй як завгодно.

- Сайт: [molfar.nova-hata.com](https://molfar.nova-hata.com)
- Google Play: [play.google.com/store/apps/details?id=com.nova_hata.molfar](https://play.google.com/store/apps/details?id=com.nova_hata.molfar)

## Як застосувати роль звідси

1. Відкрий теку ролі, наприклад [`roles/ua/advokat-dyiavola/`](roles/ua/advokat-dyiavola/)
2. Відкрий `prompt-*.md`, натисни кнопку копіювання на блоці коду
3. У застосунку: **Ролі** → створити нову → вставити в поле **Промпт**
4. Те саме зі `skill-*.md` у поле **Скіл**
5. Зберегти. Роль з'явиться в списках поряд із вбудованими

Можна інакше: зберегти `.md` на телефон і підвантажити через іконку теки в редакторі промпту — застосунок приймає `.txt` і `.md`.

У застосунку вже є 23 вбудовані ролі, тому тут лежать тільки ті, яких у ньому **немає**.

## Як додати свою роль

Маєш роль, яка добре працює — відкрий **New issue** і обери форму *Submit a role*. Заповнюєш поля, надсилаєш — роль потрапить сюди з посиланням на тебе.

Знати git не треба. Це звичайна форма.

## Про мови

- `help/` — перекладається строго, однакові файли всіма мовами
- `roles/` — **не** дзеркальні. Роль існує тими мовами, якими її хтось написав
- `models/` — тільки англійською, бо це переважно назви моделей і цифри
