# Molfar System Kit

Ролі для **Molfar System** — безкоштовного Android-застосунку, де кілька моделей ШІ проводять нараду замість одного чат-бота. Тут — готові набори ролей, які ставляться в застосунок одним файлом, і окремі ролі для ручного копіювання.

- Сайт: [molfar.nova-hata.com](https://molfar.nova-hata.com)
- Google Play: [Molfar System](https://play.google.com/store/apps/details?id=com.nova_hata.molfar)
- Довідка про застосунок: у самому застосунку («?» на кожному екрані) і на сайті — [FAQ](https://molfar.nova-hata.com/faq)

Застосунок не звертається до цього репозиторію сам: що поставити — вирішуєш ти.

---

## Що таке роль

Роль — це те, ким модель буде в розмові: **промпт** (хто вона і як говорить) і **скіл** (що й у якому порядку робить), до 10 000 символів кожен. Ролі живуть у двох каталогах застосунку:

- **Експерти** — фахівці за столом наради (місця 1–4) і в чаті з експертом;
- **Оркестратори** — ведуть нараду (місце 5): зводять відповіді, шукають розбіжності, підсумовують.

У застосунку вже є 28 вбудованих ролей. Тут — ті, яких у ньому немає.

## Поставити набір ролей (найпростіше)

Набір — це файл `.zip`, який застосунок додає до твого каталогу. Потрібен Molfar **2.0.4** або новіший.

1. Скачай набір: з [`roles/packs/`](roles/packs/) (ролі Molfar і спільноти) або з [`external/`](external/) (добірки з інших відкритих колекцій). На GitHub: файл → **Download raw file**.
2. У Molfar: **Налаштування** → **Архів даних** → **Відновити з архіву** → вибери файл.
3. Застосунок покаже, скільки в наборі ролей, — натисни **Додати**.

Нічого не видаляється і не перезапускається:

- нові ролі з'являються у своїх категоріях;
- така сама роль, що вже є, пропускається;
- роль з тією самою назвою, але іншим текстом, — вікно «Уже є»: **Замінити**, **Зберегти обидва** (з'явиться «Назва (2)») або **Пропустити**.

Ключі API, чати й наради набір не чіпає — у ньому лише ролі.

## Поставити одну роль вручну

1. Відкрий теку ролі, напр. [`roles/ua/advokat-dyiavola/`](roles/ua/advokat-dyiavola/).
2. У застосунку: на головній блок **Ролі** → **Експерти** (або **Оркестратори**) → **+** угорі → категорія, назва, опис → **Зберегти**.
3. Тап по блоку **Промпт** → встав текст з `prompt-*.md` → збережи. Те саме зі `skill-*.md` у блоці **Скіл**.

---

## Поділитися своїми ролями

**Налаштування** → **Архів даних** → **Створити архів** → **Лише ролі — для обміну**. Вийде `.zip` з твоїми й зміненими ролями — передай його друзям або колегам: вони поставлять його так само, як набір звідси.

Хочеш, щоб роль потрапила сюди, — відкрий **New issue** → форма *Submit a role*. Знати git не треба: заповнюєш поля, надсилаєш, роль з'явиться з посиланням на тебе.

**Мови.** Ролі не дзеркальні: роль існує тими мовами, якими її хтось написав. Мова ролі не задає мову відповіді — модель відповідає мовою питання.

**Моделі.** Списків моделей тут немає: застосунок сам завантажує моделі кожного провайдера по API (**Налаштування ШІ** → картка провайдера → **Моделі** → **Завантажити з API**). Ключі — твої; провайдери — Google Gemini, OpenAI, Anthropic Claude, OpenRouter, NVIDIA NIM або будь-який OpenAI-сумісний сервіс.
